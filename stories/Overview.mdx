# Silica 1.0 Amalfi

Tokens and components of the Amalfi UI kit, exported from the Sketch source
(`Silica 1.0 Amalfi UI Kit.sketch`). Components are drawn live from the exported layer trees, so
they match the kit geometry exactly.

- **Tokens**: colours (light and dark), typography, glass, spacing, radii, shadows, motion.
  The same values are in `tokens/tokens.json`, `tokens.css` and `tokens.rs`.
- **Motion → Animation Lab**: preview springs and fades on any component, then copy the animation as Rust or JSON.
- **Components**: every master of the kit, with Variant and Appearance controls and an "all variants" gallery.
